# 桌宠皮肤与动画协议规范（Skin & Animation Spec）

适用版本：desktop-pet ≥ 0.5.1 · 与社区 Codex 桌宠契约（[hr567/codex-pets](https://github.com/hr567/codex-pets)、[crafter-station/petdex](https://github.com/crafter-station/petdex)）兼容

本文是皮肤精灵图的**权威规范**：包结构、几何、状态行、逐帧时长、注视罗盘、校验规则与动画驱动协议。契约的单一事实源是 `pet/skins.mjs`，渲染实现见 `pet/renderer/pet.js`——本文与代码冲突时以代码为准并提 issue。制作教程与 prompt 模板见 [SKIN_PROMPT.md](SKIN_PROMPT.md)。

## 1. 皮肤包结构

```
my-skin/
├── pet.json          # 清单（必需）
└── spritesheet.png   # 精灵图（必需；webp/png 均可，须带 alpha 通道）
```

一个皮肤 = 一个目录，放在任一发现目录（§6）下即可，无需注册。

### pet.json 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | ✓ | 皮肤唯一标识；同 id 冲突时先扫到的目录生效 |
| `displayName` | string | ✓ | 菜单与气泡里显示的名字 |
| `description` | string | | 介绍 |
| `spriteVersionNumber` | number | | `1` 或 `2`（v2 = 含注视图）；缺省按图集尺寸推断 |
| `spritesheetPath` | string | ✓ | 精灵图**相对**本目录的安全路径（见 §5 安全规则） |
| `layout` | object | | 自定义版式（见 §2.3），一般不需要 |

## 2. 图集几何

### 2.1 标准尺寸

| 版本 | 网格 | 每格 | 总尺寸 | 内容 |
|---|---|---|---|---|
| v1 | 8 列 × 9 行 | 192×208 | **1536×1872** | 九个状态行 |
| v2 | 8 列 × 11 行 | 192×208 | **1536×2288** | 状态行 + 注视图 |

每格纵横比 192/208 ≈ 0.923。列数固定为 8（状态机按行号取行、按 8 列取格）。

### 2.2 缩放容忍（0.4.2+）

不必精确标准尺寸——满足以下几何即按实际格尺寸接受，**任意倍率（2×、0.5×、1.5×…）直接可用**：

- 宽度能被 8 整除；
- 高度能被 9（v1）或 11（v2）整除；
- 推导出的格子纵横比与 192/208 偏差 ≤ 3%。

### 2.3 校验优先级（加载时）

1. `pet.json` 显式声明 `layout` 且 `cols×cellW`、`rows×cellH` 与图片实际像素**精确吻合** → 采用声明；
2. 按 §2.2 几何推导 → 标准 8×9 / 8×11；
3. 都不满足 → **拒播**（气泡提示「皮肤尺寸对不上契约」），不会画出错位网格。

自定义 `layout` 字段：`{ cols, rows, cellW, cellH, lookRows, version }`。约束：`cols` 当前必须为 8；状态行 0~8 必须存在（`rows ≥ 9`）；要注视支持需 `rows ≥ 11` 且 `lookRows = 2`。

## 3. 状态行总表（动画协议核心）

每行从左到右按帧播放；**帧数是契约的一部分**——末列经常是空格（透明），按帧数播而不是每行都播满 8 格，否则宠物会周期性闪没。

| 行 | 状态 id | 帧数 | 逐帧时长 (ms) | 语义 | 主要触发 |
|---|---|---|---|---|---|
| 0 | `idle` | 6 | 280,110,110,140,140,320 | 待机呼吸 | 默认状态 |
| 1 | `running-right` | 8 | 120×7, 220 | 向右跑 | 拖拽右移 / 甩出飞行向右 |
| 2 | `running-left` | 8 | 120×7, 220 | 向左跑 | 拖拽左移 / 甩出飞行向左 |
| 3 | `waving` | 4 | 140,140,140,280 | 挥手 | 被戳（单击）/ 拖放结束 / 任务完成（turn_completed） |
| 4 | `jumping` | 5 | 140×4, 280 | 跳跃庆祝 | `pet_emote` 手动指定；活动事件的「任务完成」走 waving（渲染器另叠加 ±26px 弹跳位移） |
| 5 | `failed` | 8 | 140×7, 240 | 出错委屈 | 任务失败 |
| 6 | `waiting` | 6 | 150×5, 260 | 等待用户 | 等审批 / 等输入 |
| 7 | `running` | 6 | 120×5, 220 | 干活小跑 | agent 执行任务中 |
| 8 | `review` | 6 | 150×5, 280 | 复核思考 | 思考中 |
| 9~10 | `look` | 16 格（8×2） | 单帧定格 | 16 方位注视 | 指针悬停近旁（仅 v2，见 §4） |

### 3.1 状态怎么被驱动

- **宿主活动事件**（SecAgent ≥ 0.3，优先）：回合开始（`turn_started`）→ `review`（思考态）；工具调用开始 → `running`、工具返回 → `review`；等待确认 → `waiting`；完成（`turn_completed`）→ `waving`（挥手）；失败 → `failed`；用户中断 → `waiting`。精确映射见 `main.mjs` 的 `ACTIVITY_MAP`；事件语义见 [SESSION_EVENTS.md](SESSION_EVENTS.md)。
- **交互事件**（渲染页）：单击戳 → `waving`；双击摸头 → 开心台词；拖拽超过 6px → 行 1/2（按总位移方向）；**甩出飞行**（0.5.0+）继续用行 1/2（按飞行水平速度方向），播放速率随速度加快；久无互动 → `sleeping`（复用 idle 行 + 整体调暗滤镜）。
- **兜底**：老宿主无活动事件时，由模型手动调 `pet_emote` 切换同一名单的状态。

### 3.2 扩展新状态（面向贡献者）

当前动画集是**封闭的九态 + 注视**——皮肤作者不能通过 pet.json 声明任意新状态（`layout` 只改几何）。要新增一个动画状态需要改插件四处：`pet/skins.mjs` 的契约表（行定义 + 帧时长）、`pet/state.mjs` 的状态机、渲染层行选择逻辑、`main.mjs` 里 `pet_emote` 工具的 emote 枚举（老宿主无活动事件时靠它兜底驱动，漏改则新状态在老宿主上永远触发不了）；若要宿主事件驱动，还需在活动事件映射中接线。欢迎 PR，改契约表时同步更新本文。

## 4. 注视图（v2）

- 网格：行 9 放第 0~7 格（方位 `000`~`157.5`），行 10 放第 8~15 格（方位 `180`~`337.5`）；
- 罗盘约定：`000` = 角色面朝正上，**顺时针**每 22.5° 一格——0=上、4=右、8=下、12=左；
- 语义：指针在角色近旁（12~900px）且状态为 `idle/waiting/sleeping` 时，定格到最接近方位的一格；
- v1 皮肤没有注视行：指针在左侧时渲染器对素材做水平翻转示意。

## 5. 安全与资源规则

- `spritesheetPath` 必须是皮肤目录内的**安全相对路径**：拒绝绝对路径、`../`、URL（`http:` 等）、含 `?`/`#`。皮肤来自公开商店，越界路径 = 任意本地文件读；
- 本地服务只绑 `127.0.0.1` 随机端口 + 随机 token，皮肤文件按 id 白名单发放；
- 建议帧内主体居中、四周留 ~10% 透明边：点击热区按每格 **alpha > 24** 的包围盒计算，整格不透明会让热区退化成矩形（影响点击穿透精度）。

## 6. 皮肤发现目录

扫描顺序（同 `id` 先扫到的生效）：

| 顺序 | 目录 | 来源 |
|---|---|---|
| 1 | `<插件>/skins` | 插件自带 |
| 2 | `~/.codex/pets` | Codex 官方 |
| 3 | `~/.petdex/pets` | `npx petdex install` 安装 |
| 4 | `$PETDEX_PET` | petdex 桌面端约定 |
| 5 | `codexPetsDir` 设置项 | 自定义 |
| 6 | `customSkinDirs` 设置项（分隔符隔开多个） | 自定义 |

也可用 `pet_store` 工具从 petdex 商店搜索安装。没有皮肤时显示内置小鲸鱼兜底形象。

## 7. 兼容性承诺

- **v1 / v2 社区皮肤零转换即用**——这是本插件的第一设计约束；
- 0.4.2 起接受任意倍率的同构图集（此前超大图集被静默拒播，用户被迫在线压缩——已修复）；
- 0.5.0 的甩出物理**不要求皮肤新增行**：飞行复用跑步行，旧皮肤直接获得新交互；
- 契约表（帧数与逐帧时长）的任何变更都视为破坏性变更，须升主版本号。

## 8. 上架前自检清单

- [ ] 总尺寸满足 §2（精确标准值或整倍缩放，纵横比偏差 ≤ 3%）
- [ ] 背景透明（webp/png 带 alpha）；JPEG 不透明，热区会变矩形
- [ ] 逐行帧数与 §3 表一致；行内不足 8 帧的末列留透明
- [ ] 注视图 16 格方位按罗盘顺序（仅 v2）
- [ ] `pet.json` 必填字段齐全，`spritesheetPath` 为相对路径
- [ ] 放入发现目录后 `pet_skin` 切换实测：无「尺寸对不上契约」气泡、逐状态点一遍
